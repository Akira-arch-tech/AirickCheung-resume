# JuJubit 供应链接手：21 天作战模板

面向入职前 21 天，优先解决三件事：**履约品控、产能稳定、清库存**。

## 怎么用

1. 把本目录下的 `.csv` 导入飞书多维表格 / Excel / 腾讯文档。
2. 入职 D1 先建好「每日作战板」，当天开始填数（没有系统就手工填）。
3. 每天站会只看作战板 5 个核心数；清仓、产能、品控用另外三张表。

## 文件说明

| 文件 | 用途 | 何时用 |
|------|------|--------|
| `01-每日作战板.csv` | 每天必填，对外同步口径 | D1 起每天 |
| `02-清仓四类判定与进度.csv` | 存量分层 + 日清进度 | D5 起，每日更新动销 |
| `03-产能日历.csv` | 未来 14 天可承诺量与三色灯 | D11 起，每日确认 |
| `04-品控闸门与不良跟踪.csv` | 临时品控规则 + 不良/客诉归因 | D3 起建规则，D9 起严格执行 |
| `05-21天检查清单.md` | 打钩用 | 每晚自检 |

## 每天 5 个核心数（作战板）

1. 今日应发 / 实发 / 逾期  
2. 不合格 / 重打 / 客诉新增  
3. 产能状态（绿/黄/红）  
4. 滞销库存金额 + Top SKU  
5. 今日清仓出货金额/件数  

## 清仓四类（一句话）

- **A 还能卖**：正价/正常活动优先清  
- **B 微瑕**：降价、内购、达人福利，不回流正价仓  
- **C 滞销完好**：清仓价/套装，必须有截止日期  
- **D 死货**：报废或拆件，尽快释放库位
