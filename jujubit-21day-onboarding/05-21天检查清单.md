# 21 天接手检查清单

每天收工前打钩。目标：迅速接手、平稳过渡，先压住履约品控 / 产能稳定 / 清库存。

---

## 第 1 周｜止血（D1–D7）

### D1–D2 跟单摸真相
- [ ] 加齐关键人：生产/外协、质检、仓储发货、客服
- [ ] 跟完至少 10 单全链路（下单→出模/修模→生产→质检→出库）
- [ ] 写出「卡点地图」：哪里慢、哪里坏、谁能解开
- [ ] 每日作战板建好，开始填 5 个核心数

### D3–D4 品控与产能摸底
- [ ] 不良 Top5 原因列出
- [ ] 写出「稳产能日上限」（自有+外协分开）
- [ ] 分清：对外承诺交期是按峰值还是按稳产能
- [ ] 品控表里起草至少 3 条临时规则（先不求完美）

### D5–D7 库存分层启动
- [ ] 存量按金额导出清单
- [ ] 完成 A/B/C/D 四类初分（先分金额 Top80%）
- [ ] 清仓进度表有责任人 + 截止日期
- [ ] 本周清仓目标（金额/件数）与运营对齐

**第 1 周末合格线**：能说清「日稳发多少、逾期主因、库存还剩多少钱」。

---

## 第 2 周｜接手（D8–D14）

### D8 权责对齐（与分公司负责人/CMO）
- [ ] 书面确认 30 天临时目标：逾期率、客诉、清仓金额
- [ ] 确认你的权限：改交期 / 限流 / 外协加减单 / 报废审批到哪一级
- [ ] 确认爆单时谁有权对运营说「不能接」

### D9–D10 品控闸门上线
- [ ] QC-01～QC-03（或等价 3 条）正式执行
- [ ] 重打单独立通道跑通
- [ ] 客诉当日归因开始留记录

### D11–D12 产能稳定
- [ ] 未来 14 天产能日历填完并与外协确认
- [ ] 绿/黄/红灯规则与运营对齐（最好群公告）
- [ ] 约定：大促/投放前 48 小时必须问供应链

### D13–D14 清库存加速
- [ ] A/B 类每日盯动销
- [ ] C/D 类有「库位释放日」，到期强制决策
- [ ] 死货挪低优先级库位，正品与在产单优先

**第 2 周末合格线**：进度不靠「找老人问」，能靠三张表回答。

---

## 第 3 周｜立规矩（D15–D21）

### D15–D17 节奏固定
- [ ] 三张表有固定更新人与更新时间
- [ ] 30 分钟周会开起来（履约/产能/清仓）
- [ ] 每周只保留 1 个主攻重点

### D18–D21 交接完成
- [ ] 一页「接手声明」交给领导（现状/规则/30天数字/要的支持）
- [ ] 逾期、不良、库存金额出现可解释变化（降了，或清楚为何没降）
- [ ] 新人/协作方知道出问题找谁、看哪张表

**D21 合格线**：你已成为履约-产能-库存问题的第一应答人。

---

## 清仓四类判定（贴在表头）

| 类型 | 判定（满足为主） | 处理 |
|------|------------------|------|
| A 还能卖 | 完好 + 近 30 天有动销或仍是在售主推 | 正常渠道优先清 |
| B 微瑕 | 微瑕/包装问题，功能可用 | 降价、内购、达人福利；禁止回流正价仓 |
| C 滞销完好 | 完好但库龄高、近 30 天不动销或极弱 | 清仓价/套装；必须有截止日期 |
| D 死货 | 残次、过季无渠道、修复不经济 | 报废/拆件；尽快释放库位 |

边界不清时：**先按金额从高到低分，宁可暂标 C，也不要让货没有负责人。**

---

## 产能三色灯（贴在群公告）

| 灯 | 含义 | 动作 |
|----|------|------|
| 绿 | 占用 ≤ 稳产能 80% | 正常接单 |
| 黄 | 占用 80%–100% | 新活动单需供应链审批 |
| 红 | 超 100% 或关键故障 | 只保在途；不接新活动/投放单 |
