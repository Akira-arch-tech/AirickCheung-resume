# 群公告模板：产能三色灯 + 接单规则

> 发给：运营 / 投放 / 客服 / 仓配 / 生产外协  
> 建议 D12 前发出，领导知晓即可

---

【供应链接单规则 - 即日起执行】

为保障履约时效与品质，接单按「稳产能」管理，不按峰值硬扛。

**每日产能灯（以供应链当日同步为准）**
- 🟢 绿：占用 ≤ 稳产能 80% → 正常接单  
- 🟡 黄：占用 80%–100% → 新活动/投放单须供应链审批后再承诺  
- 🔴 红：超过 100% 或关键故障 → 只保在途订单；不接新活动/投放

**活动与投放**
- 大促、投放、爆款加码前 **至少提前 48 小时** 同步预估单量
- 未同步导致超产能，交期以供应链重排为准

**品控（同步执行）**
- 不良 Top 原因订单加强检验；重打单走独立通道，不插队堵塞正常单
- 客诉需当日归因到工序（打印/修模/仓配/物流）

**清库存**
- 滞销按 A/B/C/D 分层推进；C/D 类有截止日期，到期必须决策
