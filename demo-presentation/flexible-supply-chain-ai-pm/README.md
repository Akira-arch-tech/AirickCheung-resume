# 柔性定制供应链 AI PM · 能力练习 Demo

可点击练习页，对应「跨境电商柔性定制供应链 AI 产品经理：能力与专业性」三件事：

1. **场景口述**：询价 / 打样 / 交期三个真实感案例，练「谁付钱—主流程—痛点」
2. **AI 人在环**：高杠杆步骤「相似历史单报价」——采纳 / 改价采纳 / 驳回回退
3. **最小主流程**：需求 → AI 建议价 → 人审 → 确认发出 → 记指标

## 验证指标

- **主指标**：询价首次响应时长（人工基线约 45 分钟；AI 辅助目标 ≤ 10 分钟含人审）
- **辅指标**：人工采纳率
