# JuJubit 供应链接手：21 天作战模板

角色定位：**目标管理、激励、带队**。细节由岗位负责人跑；你每天最多抓 **3 件事**，且必须有交付。

## 主矛盾（分阶段）

| 阶段 | 抓什么 |
|------|--------|
| **试用期第 1 个月** | ①履约品控 ②产能稳定 ③清库存 |
| **试用期第 2 个月起** | ④拓展供应链 + 新工艺 + 上新品类（升为主攻候选；①②③改为维持） |

第 1 个月有人推开品：进停车场，不进你当天 3 件事。

## 先看这个

- `00-管理者每日3件事与一对一.md` — 你的主节奏（含 M2）  
- `09-岗位一页纸与考核.csv` — 你定指标，下属认领  
- `10-周一周五一对一纪要.md` — 周一下午计划 / 周五下午复盘  
- `11-我的每日3件事看板.csv` — 你本人每天只填这一张  
- `12-M2拓展新工艺新品类看板.csv` — **第 2 个月**再用  

## 怎么用

1. 你本人：每天只定 3 件事 + 当日交付；周一/五下午用纪要跟 Leader 一对一。  
2. 下属：维护作战板 / 清仓 / 产能 / 品控明细；你看异常与周趋势。  
3. 每人一张「岗位一页纸」：负责哪段流程、主指标、达标线。  
4. M2：用 `12` 管开品节点；红灯日先保交付，停止拓展会议。

## 文件说明

| 文件 | 谁用 | 用途 |
|------|------|------|
| `00-管理者每日3件事与一对一.md` | 你 | 每日≤3事、M1/M2主线、指标与激励 |
| `11-我的每日3件事看板.csv` | 你 | 每天三件事与交付勾选 |
| `09-岗位一页纸与考核.csv` | 你定，下属认 | 分工、指标、考核（含 M2 岗） |
| `10-周一周五一对一纪要.md` | 你 + Leader | 周一计划 / 周五复盘 |
| `12-M2拓展新工艺新品类看板.csv` | 你 + 开发/供应 | 第 2 个月开品与拓供 |
| `01-每日作战板.csv` | 指定填报人 | 5 个核心数（你只看结果） |
| `02`–`04` | 执行岗 | 清仓 / 产能 / 品控 |
| `05`–`08` | 参考 | 检查清单、判定标准、接手声明、群公告 |

## 每天 5 个核心数（作战板，下属填）

1. 今日应发 / 实发 / 逾期  
2. 不合格 / 重打 / 客诉新增  
3. 产能状态（绿/黄/红）  
4. 滞销库存金额 + Top SKU  
5. 今日清仓出货金额/件数
